# Meliviny

Meliviny is a personal music platform designed as a premium, static progressive web app for personal-library and self-hosted listening experiences.

## Current phase

This repository is in Phase 02: design system and application shell implementation for a polished static GitHub Pages experience.

## Architecture

- HTML for semantic application shell structure
- CSS for custom design tokens, glassmorphism, layout, and responsive behavior
- vanilla JavaScript for safe app initialization, theme handling, accent switching, and shell interactions
- JSON metadata for installability and web app metadata
- web APIs only where needed for progressive enhancement

## Deployment target

The project is intended to run as a static site on GitHub Pages.

## Future direction

Music content can eventually be sourced from local files or a personal server library without requiring a custom Node.js backend for the initial experience.
