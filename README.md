# Meliviny

Meliviny is a personal music platform designed as a lightweight static progressive web app.

## Current phase

This repository is in Phase 01: project initialization and project foundation setup for a static GitHub Pages deployment.

## Architecture

- HTML for structure
- CSS for theme and layout foundation
- vanilla JavaScript for app bootstrapping
- JSON metadata for web app configuration
- web APIs only where needed for browser compatibility and progressive enhancement

## Deployment target

The project is intended to run as a static site on GitHub Pages.

## Future direction

Music content can eventually be sourced from local media files or a personal server library without requiring a custom Node.js backend for the initial experience.
